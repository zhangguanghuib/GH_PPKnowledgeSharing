4. After the agent got published to Teams, the way to open the COnnection Manage is: <br/>

```
https://copilotstudio.microsoft.com/
c2/tenants/<tenantId>
/environments/<environmentId>
/bots/<bot Schema Name>
/channels/msteams/conversations
/<ConversationId>_<botId>
/user-connections
```
