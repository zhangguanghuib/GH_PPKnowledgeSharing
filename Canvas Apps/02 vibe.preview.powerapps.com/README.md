I need an issue-reporting solution for my organization. Users should be able to submit an issue through a simple, clean form, upload or attach pictures, and add notes or descriptions. The form should include basic fields such as title, category, priority, and status. Admins should be able to view all submitted issues, filter them by category or status, reassign items to the appropriate person or team, add updates or comments, and mark issues as resolved. The system should also include dashboards that display key metrics such as open issues, issues by category or priority, resolution times, and overall trends to help monitor performance and workload.
